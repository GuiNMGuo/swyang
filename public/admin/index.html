内容管理后台

改文字、换图片、建聊天房间。保存后网站自动更新，不用装任何软件。

第一次用？点下面的按钮，一路点到底就行
按钮会打开一个已经填好权限的页面，你只需要点最下面那个绿色按钮，把生成的 github_pat_... 复制回来。
一键打开「生成令牌」页面 ↗
打开后要做什么？（点开看一眼，30 秒）
  1. Repository access 选 Only select repositories，勾上 swyang
  2. 确认 Contents 已经是 Read and write（模板已填好，一般不用动）
  3. 滑到最下面点绿色的 Generate token
  4. 复制那串 github_pat_...，回到这个页面粘到下面

令牌相当于一把只对这一个仓库有效的钥匙，存在你自己的浏览器里，不会上传到任何地方。 到期了重新生成一个即可。

怎么用

1. 上面新建房间，填房间名和密码，点保存并发布
2. 等 1~2 分钟，打开网站上的「留言」页，会看到这个房间的卡片
3. 点卡片 → 输密码 → 进去聊天。密码对了才会连上这个房间
4. 房间里的消息存在各自浏览器里，点自己消息右上角的「×」可以删掉
想换密码：点房间卡片上的「重设密码」，输入新密码，再保存发布。 旧密码立刻就进不去了。
